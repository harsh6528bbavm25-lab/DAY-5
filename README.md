# Day 5 — Exploring Image Generating Tools & Prompting

## 📌 Overview
This lab explores **AI image-generation tools and prompt engineering** in an aviation context. The activity focuses on creating photorealistic airport images, evaluating generated results, and comparing the performance of different AI image-generation tools.

## 🎯 Objectives
- Understand how detailed prompts influence AI-generated images.
- Create professional aviation-related images using AI tools.
- Compare image-generation results from different AI platforms.
- Evaluate image quality, realism, lighting, composition, and prompt adherence.
- Understand how specific instructions affect generated visuals.

## 🤖 AI Tools Used
- **ChatGPT Image Generation**
- **Google Gemini**

## ✈️ Main Activity
A detailed prompt was created to generate a photorealistic image of a female airline customer-service executive at a modern international airport check-in counter.

The prompt specified:
- Professional navy-blue uniform
- Modern airport environment
- Natural facial features and skin texture
- Camera-facing pose
- Soft natural lighting
- Shallow depth of field
- 16:9 aspect ratio
- No airline logos or readable text

## 📊 Image Evaluation
The generated images were evaluated based on:

- Prompt adherence
- Facial realism
- Natural skin texture
- Eyes and hands
- Airport environment
- Lighting direction
- Professional uniform
- Unwanted text or logos
- Overall visual quality

The document records an overall evaluation of **9.1/10 for ChatGPT** and **8.5/10 for Gemini** based on the stated criteria.

## 💡 Prompt Engineering Experiment
Two additional prompts were created to test **camera-left and camera-right lighting**.

The experiment demonstrated that changing the lighting instruction affected the direction of the strongest illumination in the generated images.

## 📚 Learning Outcomes
This lab demonstrates how carefully written prompts can control important visual elements such as **lighting, subject appearance, environment, composition, realism, and aspect ratio**.

It also highlights the importance of evaluating AI-generated images rather than assuming that every generated image perfectly follows the prompt.
